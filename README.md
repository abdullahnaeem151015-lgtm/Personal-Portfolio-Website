# Abdullah Naeem | Portfolio Website

A modern portfolio website built to present my work as a machine learning and software developer in a clean, professional, and easy-to-navigate way.

This project is more than just a personal site — it is a practical showcase of how I think, build, and communicate technical work. I designed it to highlight my projects, technical skills, and experience in a way that feels polished enough for clients, recruiters, and collaborators.

## What I built

I wanted a portfolio that feels credible, modern, and easy to use on both desktop and mobile. The site includes:
- a landing page with a clear introduction
- project case studies with structured explanations
- a skills section showing my technical strengths
- contact options for client enquiries and collaborations
- responsive layout and clean visual design
- SEO-friendly metadata for better visibility

## My workflow

I built this project from the ground up with a simple but effective workflow:

1. I started by planning the content structure and deciding how to organize the portfolio around projects, skills, and contact information.
2. I created a clean React + TypeScript foundation using Vite for a fast development setup and smooth build pipeline.
3. I structured the page content in a maintainable way so that adding or updating portfolio items would be easy without rewriting the layout.
4. I used reusable components for sections like the header, links, project cards, and contact area to keep the code organized and scalable.
5. I styled the interface with Tailwind CSS to keep the design modern, responsive, and lightweight.
6. I added project pages and supporting content to explain the problem, approach, tools, and impact behind each piece of work.
7. I focused on performance and usability, making sure the site feels fast and polished instead of over-designed.
8. Finally, I configured the contact form and production setup so visitors can actually reach out without leaving the website.

## Tech stack
